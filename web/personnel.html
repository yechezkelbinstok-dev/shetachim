Collect the shluchim from chabad.org

chabad.org lists who runs each center only on that center's own record, and only to a normal browser. This collects all of them (about 4,200 centers) into one file for the map. It needs a computer (a phone browser has no console).

  1. Press
  2. Open chabad.org/jewish-centers in a new tab.
  3. Open the browser console: F12 (or Ctrl+Shift+J; on a Mac Cmd+Option+J) and pick the Console tab.
  4. Paste (Ctrl+V) and press Enter. Chrome may first ask you to type allow pasting; type it, press Enter, then paste again.
  5. Leave the tab open. It goes one center at a time and slows down whenever chabad.org asks it to, so it can take a few hours. It shows its progress in the console.
  6. When it's done it downloads chabad-personnel.json. Send me that file and I'll put it on the map.

If the tab closes or the computer sleeps, open chabad.org again and paste the script again: it picks up where it stopped. In the console, savePersonnel() downloads what it has so far, and stopPersonnel() stops it.
